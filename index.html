Checks

    Method: each check is Pass (1 pt), Warn (0.5 pt) or Fail (0 pts). Score = points ÷ 10. Grades: A ≥ 90, B ≥ 75, C ≥ 60, D < 60. Live lookups use the public GitHub API; the demo repo uses a built-in snapshot taken 2026-11-24.

    How it works

    1. Enter a repo. Any public GitHub repository, as owner/repo.
    2. ShipCheck reads it. It fetches the repo, its root files and its workflows from the GitHub API.
    3. Ten checks run. README, LICENSE, .gitignore, CI, description, topics, default branch, recent activity, homepage and open issues.
    4. You get a score. Fix the red rows, re-check, and ship with confidence.
