## Post 1 — Hacker News (Show HN)

**Title:** Show HN: ShipCheck – a 30-second deploy-readiness check for any GitHub repo

**Body:**

ShipCheck runs ten deploy-readiness checks on any public GitHub repo in
seconds — README, license, CI, description, topics, default branch, recent
activity, homepage and open issues — and gives it a score and a grade.

No install, no sign-up, no backend. It calls the public GitHub API straight
from your browser.

I built it with an AI coding agent and verified it end to end with Kane CLI
(TestMu AI): Kane runs a plain-English flow in a real browser, and its
result feeds back to the agent — if Kane fails, the agent fixes it and
re-runs. Nothing ships while Kane is red. The loop (flow, runner, run logs)
is in the repo under `kane/`.

Repo: https://github.com/guosongyi427-creator/shipcheck
Demo: https://www.youtube.com/watch?v=VIDEO_ID

Built for the KaneCLI Online Hackathon. Would love to hear what checks you
would add — what is the one thing you always forget before shipping?
